# Program marks

The procs and ports tabs draw a mark next to common programs. Most marks come from Herdr's own `icons/` folder at run time, so they look the same as in Herdr's sidebar. This folder holds the marks that Herdr does not ship:

| File | Source | License |
| --- | --- | --- |
| `gunicorn.svg`, `rubyonrails.svg`, `googlechrome.svg`, `elasticsearch.svg`, `rabbitmq.svg` | [Simple Icons](https://simpleicons.org) 16.37.0 | CC0 1.0 |

The files are trimmed for 13 px use: titles removed, drawn in `currentColor`.

All names and marks are trademarks of their owners. The license above covers the drawings, not trademark rights. Herdwatch uses each mark only to show which program runs.
