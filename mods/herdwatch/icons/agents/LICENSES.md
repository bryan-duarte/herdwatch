# Agent marks

Herdwatch draws each coding agent with its own mark. Marks for the agents in Herdr.app's program table (Claude Code, Codex, Cursor, OpenCode, Gemini, Antigravity, Amp, Copilot, Crush, Kimi, Kiro, Grok, Pi, PiG, Qoder, Hermes, Mastra Code, DeepSeek Harness) and the git mark come from Herdr's own `icons/` folder at run time, so they look the same as in Herdr's sidebar. This folder holds the marks that Herdr does not ship:
